## 1. 交付物

```text
dist\
├─ VitaTrace-0.7.0-win-x64.zip
├─ VitaTrace-0.7.0-win-x64.zip.sha256
└─ VitaTrace-0.7.0-win-x64\
   ├─ VitaTrace.exe
   ├─ README.md
   ├─ install.ps1
   └─ uninstall.ps1
```

- `VitaTrace.exe`：.NET 10 自包含单文件，目标 `win-x64`；最终用户不需要安装 .NET。
- 压缩包：约 **61 MB**（64,123,960 B）；SHA256：`5F214401F9D2BCC3B21E988DA94C7A445664CAF281EB53BC4A509403866A59C1`。
- 没有放入 PDB、构建缓存、测试数据或用户数据。

生成命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\package.ps1
```

`package.ps1` 内部调用 `build.ps1 -Configuration Release -Publish`，再暂存、压缩、计算 SHA256。

## 2. 安装方式

### 2.1 绿色版

解压后直接双击 `VitaTrace.exe`。设置、日志、历史写入 `%LOCALAPPDATA%\VitaTrace`，不写程序目录。

### 2.2 按用户安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

- 安装目录：`%LOCALAPPDATA%\Programs\VitaTrace`
- 开始菜单快捷方式：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Vita Trace.lnk`
- **不需要管理员权限**，不写 `Program Files`，不写 HKLM。

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\VitaTrace\uninstall.ps1"
```

默认保留 `%LOCALAPPDATA%\VitaTrace` 的设置/日志/历史；加 `-RemoveData` 才删除用户数据。卸载前必须先退出应用，否则脚本会拒绝删除正在被占用的 exe。

## 4. 未验证 / 已知限制

1. **没有在干净 Windows 10 / Windows 11 虚拟机上跑过**；当前测试机是 Windows 11 25H2，150% DPI。
2. **项目决定不做代码签名**。Windows SmartScreen 可能提示“未知发布者”；企业环境可能直接拦截。
3. **没有自动更新**；需要用户手动下载新 zip。
4. **没有在真实双设备同时低电量时逐秒验证**，只用演示数据验证了多设备提醒逻辑。
5. **BLE PnP 读取器没有 BLE 耳机/键鼠真机验证**。
6. **托盘固定显示依赖 Windows 通知区域设置**；不同 Win11 版本/Explorer 策略可能不同。
7. **未做安装包（MSI/MSIX）**；当前是按用户 PowerShell 安装脚本，适合绿色分发。
8. 单文件首次启动会释放到临时目录，启动时间比框架依赖版略长（本机约 1–2 秒）。
